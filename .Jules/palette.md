# Palette's UX Journal

## 2025-03-03 - High-Contrast Accessible Interactive Buttons
**Learning:** When custom color schemes like light blue ("اللبني للازار") are specified, choosing text colors with WCAG-compliant contrast ratios (e.g., black text on light blue backgrounds) is essential for screen readability and visual clarity. Combining light blue with high-contrast active states elevates both accessibility and aesthetics.
**Action:** Always verify contrast ratios for custom primary button designs and implement smooth scaling animations on slide controls to signify interactivity.
